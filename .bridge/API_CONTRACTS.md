## CONTRACT-001 — Product catalog REST API

Status: `Agreed` — published by the Backend Agent in commit `5aa40de` on `implement-nestjs-product-management` and acknowledged by the Services Agent on 2026-11-14. Open questions OQ-1 through OQ-4 are resolved by the published implementation and the Services acknowledgment below.

### Conventions

- Base URL (dev): `http://localhost:3000` (override with the `PORT` env var). No global prefix.
- CORS is enabled for development.
- Content type: `application/json`. All bodies are JSON.
- `id` values are UUID strings generated by the server and immutable.
- Validation is authoritative on the server. Unknown body properties are rejected with `400`.
- Global validation pipe: `whitelist: true`, `forbidNonWhitelisted: true`, `transform: true`.

### Product resource

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `id` | string (UUID v4) | Server-generated | Immutable |
| `name` | string | Yes | Non-empty |
| `description` | string | Yes | May be an empty string |
| `price` | number | Yes | `>= 0`, at most two decimal places |
| `stock` | integer | Yes | `>= 0` |
| `isActive` | boolean | No | Defaults to `true` |

### Endpoints

| Method | Path | Request body | Success | Errors |
| --- | --- | --- | --- | --- |
| `POST` | `/products` | `CreateProductDto` | `201` + `Product` | `400` validation |
| `GET` | `/products` | None | `200` + `Product[]` | None |
| `GET` | `/products/:id` | None | `200` + `Product` | `400` invalid UUID, `404` missing |
| `PATCH` | `/products/:id` | `UpdateProductDto` (all fields optional) | `200` + `Product` | `400` validation or invalid UUID, `404` missing |
| `DELETE` | `/products/:id` | None | `204` no body | `400` invalid UUID, `404` missing |

### Request shapes

`CreateProductDto`

| Field | Type | Required | Rules |
| --- | --- | --- | --- |
| `name` | string | yes | non-empty |
| `description` | string | yes | may be an empty string |
| `price` | number | yes | `>= 0`, max 2 decimal places |
| `stock` | number | yes | integer, `>= 0` |
| `isActive` | boolean | no | defaults to `true` |

`UpdateProductDto` is a partial `CreateProductDto`; omitted fields are unchanged. `id` cannot be changed.

### Response shape

```json
{
  "id": "3f0c0f4e-6a3b-4f4b-9a5e-1d2c3b4a5e6f",
  "name": "Cotton Shirt",
  "description": "Regular fit, 100% cotton",
  "price": 19.99,
  "stock": 5,
  "isActive": true
}
```

### Error shape

NestJS default error body:

```json
{
  "statusCode": 400,
  "message": ["price must not be less than 0"],
  "error": "Bad Request"
}
```

Validation errors (`400`) have `message` as a `string[]` of violations. Other failures use a single-string `message`.

### Examples

`POST /products`

```json
{ "name": "Blue T-Shirt", "description": "100% cotton", "price": 19.99, "stock": 25 }
```

Response `201`:

```json
{
  "id": "5b0f3c0e-3a3e-4c0b-9a55-2f1d4c9e7a11",
  "name": "Blue T-Shirt",
  "description": "100% cotton",
  "price": 19.99,
  "stock": 25,
  "isActive": true
}
```

`PATCH /products/5b0f3c0e-3a3e-4c0b-9a55-2f1d4c9e7a11`

```json
{ "stock": 20, "isActive": false }
```

### Notes

- Storage is in-memory for the MVP; data resets on server restart.
- `GET /products` returns all products, including inactive ones (`isActive: false`); clients filter as needed.

## Open contract questions — resolved

| ID | Resolution | Evidence |
| --- | --- | --- |
| OQ-1 | `GET /products` returns all products. The storefront filters `isActive` on the client. The Services store exposes `activeProducts`/`activeProductById` so pages filter consistently. | Published contract notes and `apps/web/src/core/state/product.store.ts` |
| OQ-2 | `description` is required on create and update payloads. An empty string is valid. | `CreateProductDto` validation in `5aa40de` |
| OQ-3 | No `currency` field in Increment 1. `price` is a bare number; display currency is a frontend concern. | Product response schema and requirements section 7 |
| OQ-4 | No pagination, search, or sort parameters in Increment 1. Clients consume the full list. | Endpoint table contains no list query parameters |
