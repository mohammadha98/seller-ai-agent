## CONTRACT-001 — Product catalog REST API

Status: `Draft` — observed by the Core Agent from the uncommitted Backend implementation on `implement-nestjs-product-management` on 2026-11-14. This is not an agreement. The Backend Agent must confirm or amend it, and the Services Agent must acknowledge it before TASK-007 starts.

### Conventions

- Base URL: `/products`; development server default port `3000`.
- Content type: `application/json`.
- `id` values are UUID strings generated by the server and immutable.
- Validation is server-side. Unknown fields are rejected with `400`.

### Product resource

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `id` | string (UUID) | Server-generated | Immutable |
| `name` | string | Yes | Non-empty |
| `description` | string | Yes (draft) | Optionality is OQ-2 |
| `price` | number | Yes | `>= 0`, at most two decimal places |
| `stock` | integer | Yes | `>= 0` |
| `isActive` | boolean | No | Defaults to `true` |

### Endpoints

| Method | Path | Request body | Success | Errors |
| --- | --- | --- | --- | --- |
| `POST` | `/products` | `CreateProduct` | `201` + `Product` | `400` validation |
| `GET` | `/products` | None | `200` + `Product[]` | None in draft |
| `GET` | `/products/:id` | None | `200` + `Product` | `400` invalid UUID, `404` missing |
| `PATCH` | `/products/:id` | `UpdateProduct` (all fields optional) | `200` + `Product` | `400` validation or invalid UUID, `404` missing |
| `DELETE` | `/products/:id` | None | `204` no body | `400` invalid UUID, `404` missing |

### Request shapes

`CreateProduct`

```json
{
  "name": "Cotton Shirt",
  "description": "Regular fit, 100% cotton",
  "price": 19.99,
  "stock": 5,
  "isActive": true
}
```

`UpdateProduct` is a partial `CreateProduct`; omitted fields are unchanged.

### Response shape

```json
{
  "id": "3f0c0f4e-6a3b-4f4b-9a5e-1d2c3b4a5e6f",
  "name": "Cotton Shirt",
  "description": "Regular fit, 100% cotton",
  "price": 19.99,
  "stock": 5,
  "isActive": true
}
```

### Error shape

NestJS default error body:

```json
{
  "statusCode": 400,
  "message": ["price must not be less than 0"],
  "error": "Bad Request"
}
```
